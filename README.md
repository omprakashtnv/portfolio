# Om_Prakash_Gupta Portfolio

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Included

- Light/dark toggle persisted to localStorage
- Interactive WebGL 3D cube with automatic rotation and mouse/touch drag
- Procedural wireframe city and floating skill badges
- Responsive hero, three project cards, about, skills and contact placeholders

## Before publishing

- Verify all experience claims and project details
- Test on mobile and optimize WebGL performance
